# Radio Pendo Station Shianda - 96.5 FM

Live community radio website for Shianda, Kakamega. Mobile-first, offline-ready, built for low-data listeners in Mumias & Kakamega County.

**Live Demo:** https://muhsinswaleh69-max.github.io/radio-pendo/

### Features
- 🔴 Listen Live – One-tap audio player (Zeno / Icecast)
- 📅 Show Schedule – Asubuhi Pendo, Beats & Talk, Pendo Sports
- 📰 Local News & Updates
- 💬 WhatsApp Studio – Direct chat & song request
- 📢 Advertise With Us section
- 📱 PWA ready – Works on 2G

### Tech
HTML, TailwindCSS, Vanilla JS. No backend needed.

### How to Update Stream
In `index.html` line 22, replace:
`src="https://stream.zeno.fm/0r0xa792kwzuv"`
with your actual stream link.
